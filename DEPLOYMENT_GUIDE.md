# DEPLOYMENT GUIDE: BUDGETX PERSONAL FINANCE & PLANNER

This guide details the steps to deploy the **React frontend** and the **Laravel backend** along with a **MySQL database** to free/affordable production servers (**Vercel** and **Railway** or **Render**).

---

## 1. PRE-DEPLOYMENT VERIFICATION
Your codebase is fully prepared for production deployment:
1.  **Vercel Routing**: A `vercel.json` has been created inside the `frontend/` folder to allow direct refreshes on React Router paths (like `/dashboard`) without showing `404` errors.
2.  **API URL Config**: Your frontend Axios client (`frontend/src/services/api.js`) automatically points to your backend URL base dynamically using environment variables.

---

## 2. PART 1: DEPLOYING THE MYSQL DATABASE & LARAVEL BACKEND (RAILWAY / RENDER)
We recommend **Railway** or **Render** as they support both Laravel (PHP) and MySQL databases out of the box with zero complex server management.

### Option A: Deploying on Railway (Recommended - Fastest & Easiest)
1.  **Create an Account**: Go to [Railway.app](https://railway.app) and sign in using your GitHub account.
2.  **Provision MySQL**:
    *   Click **New Project** -> select **Provision MySQL**.
    *   Once database is ready, click on the **MySQL** service card, go to the **Variables** tab, and copy your database credentials:
        *   `MYSQLHOST` (e.g. `roundhouse.proxy.rlwy.net`)
        *   `MYSQLPORT` (e.g. `3306`)
        *   `MYSQLDATABASE` (e.g. `railway`)
        *   `MYSQLUSER` (e.g. `root`)
        *   `MYSQLPASSWORD` (e.g. `your-db-password`)
3.  **Deploy the Laravel Service**:
    *   Click **New** -> **GitHub Repo** -> select your repository: `Bunty3545/Real-Time-Currency-Converter-and-Budgeting-Tool`.
    *   Set the **Root Directory** of the service to: `backend`.
4.  **Add Backend Environment Variables**:
    Go to the **Variables** tab of your Laravel service card in Railway and add the following:
    ```env
    APP_ENV=production
    APP_DEBUG=false
    APP_KEY=base64:your-laravel-key-here # Generate locally with `php artisan key:generate --show`

    DB_CONNECTION=mysql
    DB_HOST=${{MySQL.MYSQLHOST}}       # Binds directly to your Railway database service
    DB_PORT=${{MySQL.MYSQLPORT}}
    DB_DATABASE=${{MySQL.MYSQLDATABASE}}
    DB_USERNAME=${{MySQL.MYSQLUSER}}
    DB_PASSWORD=${{MySQL.MYSQLPASSWORD}}

    # URLs (Replace these once Vercel and Railway domains are generated)
    APP_URL=https://your-laravel-service-url.up.railway.app
    FRONTEND_URL=https://your-react-service-url.vercel.app
    SANCTUM_STATEFUL_DOMAINS=your-react-service-url.vercel.app
    ```
5.  **Expose Domain**:
    *   In the Laravel service card -> go to the **Settings** tab -> under **Environment** click **Generate Domain** to get your public API URL.
6.  **Run Migrations**:
    *   In Railway, you can trigger migrations automatically on every deploy by adding a custom start command in Settings or by running it in the Service Shell tab:
        ```bash
        php artisan migrate --force
        ```

## 3. PART 2: DEPLOYING THE REACT FRONTEND (VERCEL - FREE)
Vercel is the premier platform for hosting React SPAs for free.

1.  **Create an Account**: Go to [Vercel.com](https://vercel.com) and log in using your GitHub account.
2.  **Import Project**:
    *   Click **Add New** -> **Project**.
    *   Import your repository: `Bunty3545/Real-Time-Currency-Converter-and-Budgeting-Tool`.
3.  **Configure Build & Development Settings**:
    *   **Project Name**: `budgetx-finance`
    *   **Framework Preset**: `Vite`
    *   **Root Directory**: Change this to `frontend` (crucial so Vercel builds the React folder, not the root).
4.  **Add Environment Variables**:
    Expand the **Environment Variables** dropdown and add:
    *   **Key**: `VITE_API_URL`
    *   **Value**: `https://your-laravel-service-url.up.railway.app/api` (The domain generated by Railway).
5.  **Deploy**:
    *   Click **Deploy**. Within 1 minute, Vercel will compile your React assets and give you a beautiful, public `.vercel.app` URL (e.g. `https://budgetx-finance.vercel.app`).

---

## 4. PART 3: CONNECTING THE TWO SERVICES (CORS SECURITY & SANCTUM)
Once both domains are generated, ensure they can communicate securely without browser CORS errors:

1.  Go back to your **Laravel backend environment variables** (on Railway/Render) and update these three variables with your new Vercel domain:
    *   `FRONTEND_URL=https://budgetx-finance.vercel.app`
    *   `SANCTUM_STATEFUL_DOMAINS=budgetx-finance.vercel.app` (exclude the `https://` prefix here).
    *   `APP_URL=https://your-laravel-service-url.up.railway.app`
2.  Redeploy/Restart your Laravel backend service.
